# Known Issues and Limitations

This document outlines known issues and limitations with the reorganized Project-Manager codebase.

## Import Paths

Some import paths may still need to be updated manually. If you encounter a "Module not found" error, check the import path and update it to reflect the new directory structure.

## Test Coverage

Some tests may need to be updated to reflect the new directory structure. If you encounter test failures, check the import paths and file references in the test files.

## MCP Server Configuration

The MCP server configuration may need to be updated to reflect the new structure. If you encounter issues with the MCP server, check the configuration files and update them as needed.

## Documentation Links

Some links in documentation files may need to be updated to reflect the new structure. If you encounter broken links, update them to reflect the new directory structure.

## Package.json Scripts

Some scripts in package.json may need to be updated to reflect the new structure. If you encounter issues with scripts, check the paths they reference and update them as needed.

## Reporting Issues

If you encounter any issues not listed here, please report them by creating an issue in the repository.
