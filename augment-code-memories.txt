
# Project Vision and Goals
- User wants to create a 'Project-Manager' project inspired by the TaskMaster codebase, with compatibility across multiple IDEs (Cursor, VS Code, etc.) and functionality to instruct LLMs/agents on tasks.
- User wants Project-Manager to focus on creating designs/blueprints for IDE coding LLMs to follow, not code itself, and should use models good at multi-modal reasoning, planning, and coding to generate optimal workflows.
- User wants Project-Manager to research existing projects using tools like Firecrawl, Tavily or Exa before starting new projects, with the goal of making development easier and more structured for LLMs/agents.
- User wants Project-Manager to focus on thorough online research before creating plans, avoid unnecessary complexity, and achieve a 99%+ success rate for project planning.
- User wants to have an initial working MVP (Minimum Viable Product) of project-manager that can be used while continuing development, prioritizing early usability over complete implementation.
